# UBA DOCES — Site do perfil

Site estático independente para o perfil do Instagram da UBA DOCES.

## Publicar na Vercel

Importe este repositório como um novo projeto chamado `uba-link-perfil`.

- Framework Preset: Other.
- Root Directory: ./.
- Build Command: vazio.
- Output Directory: padrão (raiz do projeto).

Os arquivos do site ficam em `index.html` e `assets/`. Os canais de atendimento são iFood, WhatsApp para revenda e eventos, e YouTube.

Os depoimentos da versão inicial estão identificados como demonstrativos e devem ser substituídos por avaliações reais antes da divulgação.
